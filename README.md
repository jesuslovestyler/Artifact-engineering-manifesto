# Artifact Engineering Manifesto

The founding document of **artifact engineering** — the discipline of building software through natural-language conversation with AI. Coined by Tyler, October 2026.

## What it is

Artifact engineering treats human clarity as the programming language: you describe what you want in plain words, and the SI builds working software. Conversation is the compiler.
